# 用户注册接口

`POST /api/user/register`

请求体为 JSON，用户名长度 2–50，密码长度 6–72；密码按 UTF-8 编码后不能超过
72 字节（bcrypt 的处理上限，超长会直接返回 422，不会被静默截断）。

```json
{
  "username": "jjtq",
  "password": "123456"
}
```

注册成功时返回 HTTP 200：

```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "token": "1f0c9c3f7a2b4d8e9f6a5c1b2d3e4f50",
    "userInfo": {
      "id": 1,
      "username": "jjtq",
      "bio": "这个人很懒，什么都没留下",
      "avatar": null
    }
  }
}
```

- 密码使用 bcrypt 加密后入库，数据库中不保存明文。
- `token` 为随机生成的 32 位十六进制字符串，用于前端保存登录态。
- `userInfo` 使用驼峰字段名，`bio`、`avatar` 可以为 `null`。

用户名已存在时返回 HTTP 409：

```json
{"code": 409, "message": "用户名已存在", "data": null}
```

请求体字段缺失或长度不合法时返回 FastAPI 默认的 HTTP 422 校验响应。

数据库事务由 `get_db` 统一提交；用户名唯一约束由数据库兜底。

后端开发约定见 `jjtq/backend/AGENTS.md`；手动请求示例见
`jjtq/backend/tests/users.http`。

运行测试：

```bash
uv run python -m unittest discover -s jjtq/backend/tests -v
```
