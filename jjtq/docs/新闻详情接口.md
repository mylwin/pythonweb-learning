# 新闻详情接口

`GET /api/news/detail?id=1`

`id` 为必填正整数。成功读取新闻后，浏览量原子递增 1，响应包含更新后的浏览量。
数据库事务由 `get_db` 统一提交；查询或响应构造失败时回滚。

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "title": "新闻标题",
    "content": "新闻内容",
    "image": null,
    "author": null,
    "publishTime": "2023-01-01T00:00:00",
    "categoryId": 1,
    "views": 1,
    "relatedNews": []
  }
}
```

`relatedNews` 返回同分类中除当前新闻外的最新 5 条新闻，按发布时间和 ID
降序排列。每项包含 `id`、`title`、`image`；没有推荐时返回空数组。
`image`、`author` 支持 `null`。

新闻不存在时返回 HTTP 404：

```json
{"code": 404, "message": "新闻不存在", "data": null}
```

缺少 `id` 或传入非正整数时返回 FastAPI 默认的 HTTP 422 校验响应。

从仓库根目录启动后端：

```bash
uv run uvicorn jjtq.backend.main:app --reload
```

数据库连接从 `jjtq/backend/.env` 的 `ASYNC_DATABASE_URL` 读取，也可用同名
环境变量覆盖。启动位置不影响 `.env` 文件定位。

运行测试：

```bash
uv run python -m unittest discover -s jjtq/backend/tests -v
```

测试使用内存数据库，覆盖响应字段、浏览量递增、相关推荐、空推荐、
不存在的新闻、参数校验和失败回滚。
