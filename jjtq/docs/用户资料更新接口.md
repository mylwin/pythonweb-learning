# 用户资料更新接口

`PUT /api/user/update` 更新当前登录用户的资料，需要在请求头携带令牌：

```http
Authorization: Bearer <token>
Content-Type: application/json
```

请求体至少包含一个可更新字段，未提供的字段保留原值。字段可显式传入
`null` 以清除已有值：

| 字段 | 规则 |
| --- | --- |
| `nickname` | 2–50 个字符，或 `null` |
| `avatar` | 2–255 个字符，或 `null` |
| `gender` | `male`、`female`、`unknown` 或 `null` |
| `phone` | 中国大陆手机号格式，或 `null`；非空手机号不能重复 |
| `bio` | 2–255 个字符，或 `null` |

```json
{"nickname": "新闻读者", "bio": "喜欢阅读新闻", "gender": "unknown"}
```

成功返回 HTTP 200，`data` 为更新后的资料，包含 `id`、`username`、
`nickname`、`avatar`、`gender` 和 `bio`，不包含手机号、密码或令牌。
当前用户由令牌确定，请求中不能传入 `id`、`username`、`password` 等字段。

- 令牌缺失、无效或过期：HTTP 401。
- 请求体为空、字段不合法或包含不允许的字段：HTTP 422。
- 手机号已被使用：HTTP 409；整次更新回滚。

事务由 `get_db` 提交或回滚。HTTP 请求示例见 `jjtq/backend/tests/users.http`。
