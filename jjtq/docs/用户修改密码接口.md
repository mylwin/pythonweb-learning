# 用户修改密码接口

`PUT /api/user/password` 使用 Bearer 令牌验证当前用户：

```http
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{"oldPassword": "原密码示例", "newPassword": "新密码示例"}
```

请求字段使用 `oldPassword` 和 `newPassword`，也兼容内部蛇形字段名。
密码均需为 6–72 个字符，UTF-8 编码后不得超过 72 字节；新密码不能与旧密码相同。

成功返回 HTTP 200：

```json
{"code": 200, "message": "密码更新成功，请重新登录", "data": null}
```

成功后该用户的全部已签发令牌失效，需使用新密码重新登录；其他用户的
密码和令牌不受影响。密码更新和令牌撤销由同一个数据库事务提交或回滚。

- 旧密码错误或新密码与旧密码相同：HTTP 400，现有令牌继续有效。
- 令牌无效、缺失或已过期：HTTP 401。
- 密码在请求处理期间被其他请求修改：HTTP 409，请重新登录。
- 请求字段缺失、类型或长度不合法：HTTP 422；错误响应不会包含输入密码。

HTTP 请求示例见 `jjtq/backend/tests/users.http`。
