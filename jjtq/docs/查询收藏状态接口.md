# 查询收藏状态

`GET /api/favorite/check?newsId=1` 查询当前登录用户是否收藏指定新闻，
需要在请求头携带 `Authorization: Bearer <token>`。`newsId` 是必填正整数。

成功返回 HTTP 200：

```json
{"code": 200, "message": "success", "data": {"isFavorite": true}}
```

`isFavorite` 为 `false` 表示当前用户没有对应收藏记录；新闻不存在时也返回
`false`。令牌缺失、无效或过期时返回 HTTP 401；新闻编号缺失或不合法时返回
HTTP 422。查询的用户由令牌确定，不接受客户端指定用户 ID。

该接口仅查询状态；新增、取消、列表及清空收藏不属于此接口。手动请求示例见
`jjtq/backend/tests/favorite.http`。
