# 收藏列表与清空

两个接口均需携带 `Authorization: Bearer <token>`，凭证缺失、无效或
过期时返回 HTTP 401。用户身份由令牌确定，无需传入用户 ID。

## 获取列表

`GET /api/favorite/list?page=1&pageSize=10`

- `page` 默认为 1，必须大于等于 1。
- `pageSize` 默认为 10，范围为 1–100。
- 参数不合法时返回 HTTP 422。

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 10,
        "title": "新闻标题",
        "description": null,
        "image": null,
        "author": null,
        "publishTime": "2026-10-28T10:00:00",
        "categoryId": 1,
        "views": 0,
        "favoriteTime": "2026-10-28T12:00:00"
      }
    ],
    "total": 1,
    "hasMore": false
  }
}
```

`id` 为新闻 ID，可直接用于新闻详情和取消收藏接口。列表按收藏时间、
收藏记录 ID 倒序排列，同一时间的记录也有稳定顺序。仅返回新闻摘要，
不返回正文。新闻已删除的收藏不会出现在列表或 `total` 中。

`total` 为当前用户全部有效收藏数量，`hasMore` 表示当前页之后是否
还有记录。空列表返回 `list: []`、`total: 0`、`hasMore: false`。
页码超出范围时返回空列表，并保留实际总数。

## 清空收藏

`DELETE /api/favorite/clear`，无请求体。

```json
{"code": 200, "message": "清空收藏成功", "data": null}
```

只清空当前登录用户的收藏，包括新闻已删除的残留记录。空列表重复
清空仍返回成功，其他用户的收藏不受影响。事务由数据库依赖统一提交
与回滚，发生异常时不会保留部分删除结果。

手动请求示例见 `jjtq/backend/tests/favorite.http`。
